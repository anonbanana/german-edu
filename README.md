# German Edu Site

## Overview
This project is a website for educational content related to the German education system.

## Features
- Home page with introduction and main sections.
- Educational resources and links.
- Contact information for inquiries.

## Setup Instructions
1. Clone the repository:
   ```sh
   git clone https://github.com/anonbanana/german-edu.git
   ```
2. Navigate to the project directory:
   ```sh
   cd german-edu-site
   ```
3. Run the project:
   ```sh
   python main.py
   ```
